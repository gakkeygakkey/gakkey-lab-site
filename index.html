Bridge Meter & Bridge Plugin

常時表示しやすい
小さなメーター

DAW内のBridge PluginやMacのオーディオ入力に加え、Macから出ている音も複雑な設定なしで直接キャプチャ。 入力に「System Audio Out」を選択するだけでメータリングできます。

Flexible panels

同時に見たいパネルは
分離できます

ラウドネス、アナライザーは一時的に分離表示できます。
Reference Levelも用途に合わせて変更できます。

Bridge Plugin System Audio Input System Audio Output AAX / VST3 / AU

Bridge Pluginも用意

AAX / VST3 / AU対応のBridge PluginをDAWに挿して、Bridge Meterへ表示用信号を直接送信。 System Audio Outより低遅延で、他のアプリの音も混ざりません。 プラグインはメーター表示用の信号だけを送信し、音声そのものは変更しません。

Relative Time Counter

任意の位置で
カウンターを0に

MTC / MMCを使って、任意の位置をREL=0として表示。 クライアントから伝えられた「1:30」の場所へ、迷わずロケートできます。

  • REL / ABS表示切り替え
  • MTC / MMC対応で、さまざまなDAWと連携
  • 相対時間またはタイムコードでロケート
  • Pro ToolsではPTSL SDKによる連携にも対応
  • Auto Talkback機能
